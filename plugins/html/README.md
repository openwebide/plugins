# HTML

Syntax, folding, source structure and editing rules for HTML. Language contributions: HTML.

This independent component uses the public API 5 SDK and executes on the selected
project host, with no host capabilities or browser code. Installation, updates,
provider preferences, disablement and removal use the ordinary plugin lifecycle.
Related dialects share a package according to intended language-server coverage;
LSP execution is the following app roadmap item.

Embedded bodies resolve through installed language providers and their preferences. Missing or disabled providers leave those bodies plain.
